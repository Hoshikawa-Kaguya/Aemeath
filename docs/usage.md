# 使用说明

中文 | [English](usage.en.md)

本文中的"输入""输出"都从 Aemeath 的视角命名：声音进入 Aemeath 的是输入，离开 Aemeath 的是输出。术语的完整定义见 [`GLOSSARY.md`](../GLOSSARY.md)。

## 1. 安装与首次启动

1. 从 [Releases](https://github.com/Hoshikawa-Kaguya/Aemeath/releases) 下载安装版 `Aemeath-win-Setup.exe` 运行，或者解压便携版后运行 `Aemeath.exe`。
2. 第一次启动时，如果还没有安装 usbip-win2 驱动，Aemeath 会说明原因并请你同意安装。安装需要一次管理员权限（UAC），大约一分钟；完成后可能要重启电脑。
3. 驱动可用后，Aemeath 会注册它的 16 个虚拟设备。第一次注册时 Windows 要为每个设备装驱动，可能需要一分钟左右，期间界面上会显示进度。
4. 工作台一开始是空的，可以点"使用工作台预设"，得到一个虚拟输入和一个虚拟输出，再按需要添加节点。

关闭窗口后 Aemeath 留在通知区域（托盘）里继续工作；从托盘菜单选"退出 Aemeath"才会真正退出。Aemeath 运行时再从开始菜单或任务栏启动，会直接打开已运行的窗口。

## 2. 工作台

工作台上的每个方块是一个**节点**，节点之间的线是**连线**。声音沿连线从左侧的输入节点流向右侧的输出节点，中间可以经过**总线**（把几路声音合在一起再分发出去）。

| 节点类型 | 用途 |
|---|---|
| 外部输入 | 这台电脑上的麦克风或其他录音设备 |
| 外部输出 | 耳机、音箱或其他播放设备 |
| 虚拟输入 | 一个虚拟播放设备，应用可以把声音播放到这里 |
| 虚拟输出 | 一个虚拟录音设备，OBS 等应用可以从这里录制 |
| 应用源 | 某个程序的声音，不管它在哪个设备上播放 |
| 总线 | 把送进来的声音求和后再分发出去 |
| 外部插入 | 把声音送进外部程序（例如 NVIDIA Broadcast）处理后再取回 |
| 录音节点 | 把送进来的声音写成文件 |

常用操作：

- **添加节点**：工具栏的"添加节点"，或在空白处右键"在此处添加节点…"。外部设备在添加时就可以选好独占或共享、格式和缓冲。
- **连线**：从节点右侧的端口拖到另一个节点上，放在整个节点上即可，不必对准端口。不能连的节点在拖动时会提示原因。
- **调增益**：通常直接调节点的增益。需要单独调某条连线时，右键连线选"显示连线标签"，鼠标停在标签上滚动滚轮，每格 1 dB；单击标签上的圆点开关连线。标签可以沿连线拖动，免得互相遮挡。连线标签默认不显示。
- **删除**：选中节点或连线后按 Del。删除节点前会先确认，删除后不能恢复；连线直接删除。
- **节点设置**：节点右上角的"⋯"或右键菜单，可以改名、换槽位、设门限、改设备格式和重采样算法等，点"确定"后生效。

右侧的**路由矩阵**以"信号源 × 目的地"的网格列出所有连线：单击格子新建或开关连线，停在格子上滚动滚轮调增益。下方的**控制台**把常用的节点排成竖条，用"固定节点"或节点菜单里的"固定到控制台"把节点放进去，在这里调增益、门限和静音。

## 3. 虚拟设备与按应用分轨

Aemeath 有 8 个虚拟输入和 8 个虚拟输出。它们在 Windows 里的名字是固定的：

- 虚拟输入是播放设备，例如"扬声器 (Aemeath In 1)"。把应用的输出设备选成它，声音就进了 Aemeath。
- 虚拟输出是录音设备，例如"线路 (Aemeath Out 1)"。在 OBS、Discord 里把它选作麦克风或音频输入，就能录到 Aemeath 送去的声音。

只有被节点使用的虚拟设备才会出现在 Windows 里，没用到的会自动拔出，不会把设备列表弄乱。**设备**页列出全部 16 个槽位的状态和格式。

把应用分到不同的虚拟输入，有两种方法：

- 在**应用**页给正在出声的程序选**落点**。指派按程序保存，以后每次启动都生效。有的程序（例如 Discord、部分游戏）自己选择设备，对它们指派无效，需要在程序里设置。
- 添加**应用源**节点：在应用照常播放的同时复制一份它的声音，不改变它的落点。如果同一个程序的落点和应用源最后送到了同一个地方，那里会听到两份声音，Aemeath 会给出警告。

一个常见的直播布局：

```
麦克风（外部输入）→ 外部插入（NVIDIA Broadcast 降噪）→ 虚拟输出（OBS 录制）
游戏、音乐（落点为虚拟输入）→ 总线 → 耳机（外部输出）
                                  └→ 虚拟输出（OBS 录制）
```

## 4. 外部设备

外部设备默认以**独占**方式打开：声音不经过 Windows 的混音和重采样，延迟更低，但其他程序不能同时使用它。如果某个设备需要与其他程序共用，在节点设置里改为共享。

设备被拔出或被其他程序占用时，节点显示为**离线**，并说明原因；设备恢复后自动重新接入，不需要重启 Aemeath。需要立即重试时，用节点菜单的"重新检测设备"，或托盘、设置页里的"重新检测全部设备"。

## 5. 录音与热键

- **录音**：在工作台上添加录音节点，把要录的声音连过去。在**录音**页或控制台上开始、停止录音，并设置录音文件夹和格式（FLAC 或 WAV）。WAV 文件接近 4 GB 时自动分段；主程序重启时录音不会中断。
- **热键**：在**热键**页设置。**全局热键**控制整体操作：全部录音节点开始或停止、紧急静音（让所有输出节点静音）、显示或隐藏主窗口。**专属热键**属于某个节点或连线（静音、连线开关、录音），在节点设置或连线菜单里设置。每个热键可以选"切换"（按一下取反）或"按住生效"（按住期间取反，松开后恢复）。也可以用鼠标侧键。

## 6. 设置

- **引擎采样率**：Aemeath 内部混音使用的采样率，修改不需要重启。
- **默认重采样算法**：在音质、延迟和处理开销之间取舍，也可以在节点设置里单独指定。
- **开机自启动**、**深浅色**、**主题色**、**背景图**、**语言**。
- **检查更新**：发现新版本后可以下载，并在重启时安装。安装版和便携版都可以这样更新。

## 7. 卸载

- **安装版**：在 Windows 的"已安装的应用"里卸载。卸载时会请求一次管理员权限，用来移除 Aemeath 的虚拟设备；拒绝也能完成卸载，只是设备会留在系统里。
- **便携版**：删除文件夹之前，先在设置页执行"移除虚拟设备"（需要管理员权限），再删除文件夹。配置在 `%APPDATA%\Aemeath`，不需要时可以一并删除。

usbip-win2 驱动不会随 Aemeath 一起卸载，其他程序可能也在用它；不需要时可以在"已安装的应用"里单独卸载。

## 8. 反馈问题

请在 [Issues](https://github.com/Hoshikawa-Kaguya/Aemeath/issues) 里描述问题，并附上日志：设置页的"打开日志目录"（`%APPDATA%\Aemeath\logs`）。如果 Aemeath 崩溃过，可以在设置页启用"崩溃转储"，之后的崩溃会在数据目录里留下诊断文件，一并附上更容易查清原因。
